## Key

Exact probability = 3/5. (P(7 before 5) = P(7)/(P(7)+P(5)) = (6/36)/((6+4)/36) = 6/10 = 3/5.) A correct answer must give exactly this reduced fraction.

## Answer

**Answer: 3/5.**

**Per-roll probabilities (from the 36 equally likely ordered outcomes of two fair dice):**
- Sum = 7: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1) → 6 outcomes → P(7) = 6/36 = 1/6.
- Sum = 5: (1,4),(2,3),(3,2),(4,1) → 4 outcomes → P(5) = 4/36 = 1/9.

(Crucial: the 11 possible sums 2–12 are NOT equally likely; you must count ordered pairs.)

**Why the answer is a simple ratio.** On any roll, three things can happen: a 7 (prob 6/36), a 5 (prob 4/36), or neither (prob 26/36). A "neither" roll is neutral — it decides nothing, and because rolls are independent (memorylessness), it leaves the situation exactly as it was. So the contest is settled only by the first roll that lands on 7 or 5, and the winner is whichever of those two it is. Conditioning on that first decisive roll, the neutral probability cancels identically:

  P(7 before 5) = P(7) / (P(7) + P(5)) = 6 / (6 + 4) = 6/10 = **3/5**.

**Two independent cross-checks (both confirm 3/5):**
- *First-step recurrence:* let x = P(7 before 5). Then x = 6/36 + (26/36)·x ⟹ (10/36)x = 6/36 ⟹ x = 6/10 = 3/5.
- *Geometric series:* Σ_{k≥0} (26/36)^k · (6/36) = (6/36) / (1 − 26/36) = (6/36)·(36/10) = 6/10 = 3/5.

**Loose ends handled.** A single roll cannot be both 7 and 5, so there is no within-roll tie. The chance the game never decides is (26/36)^n → 0, so the process terminates with probability 1 and no mass is lost. Orientation sanity check: 7 is the more likely single-roll event (6 vs 4 ways), so its win probability should exceed 1/2 — and 3/5 > 1/2. The complementary event, 5 before 7, is 2/5, and 3/5 + 2/5 = 1.

**Final reduced fraction: 3/5.**
