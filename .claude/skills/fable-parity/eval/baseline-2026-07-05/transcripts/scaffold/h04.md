## Answer: 2,555,757

There are exactly **2,555,757** binary strings of length 24 over {0,1} that contain no run of three or more consecutive 1s (i.e. "111" never appears as a substring — this also excludes "1111", "11111", etc., since any such run contains "111").

## The recurrence and why it holds

Let a(n) be the number of valid length-n binary strings (no "111"). Because a run of 1s can never reach length 3, the **maximal trailing run of 1s** of any valid string is 0, 1, or 2. Classify every valid string (for n ≥ 3) by that trailing run — the three cases are mutually exclusive and exhaustive:

- **ends in `0`** (0 trailing 1s): delete the final `0`; what remains is an arbitrary valid string of length n−1 → **a(n−1)**
- **ends in `01`** (exactly 1 trailing 1): delete the final `01`; what remains is an arbitrary valid string of length n−2 → **a(n−2)**
- **ends in `011`** (exactly 2 trailing 1s): delete the final `011`; what remains is an arbitrary valid string of length n−3 → **a(n−3)**

The `0` that immediately precedes each trailing run makes the split unambiguous, and appending a `0`-terminated block to any valid string can never create a new "111". Hence the **tribonacci recurrence**:

**a(n) = a(n−1) + a(n−2) + a(n−3)**

(This is the "no three consecutive 1s" analogue of the classic Fibonacci "no two consecutive 1s" problem, which forbids "11" and uses a(n)=a(n−1)+a(n−2). Here we forbid "111", so three terms.)

## Base cases (by direct enumeration)

- a(0) = 1 (the empty string)
- a(1) = 2 ("0", "1")
- a(2) = 4 ("00", "01", "10", "11")

Consistency check: a(3) = a(2)+a(1)+a(0) = 4+2+1 = 7, which equals 2³ − 1 = all 8 length-3 strings except "111". Correct.

## Indexing convention

a(n) counts strings of length exactly n. Seeds sit at n = 0, 1, 2, so iterating up to n = 24 lands precisely on length 24 (no off-by-one).
