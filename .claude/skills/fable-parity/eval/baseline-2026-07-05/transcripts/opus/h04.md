## Key

Exact count = 2555757. (Satisfies a tribonacci-like recurrence a(n)=a(n-1)+a(n-2)+a(n-3).) A correct answer must give exactly this integer.

## Answer

**Answer: 2,555,757**

## The recurrence

Let $a(n)$ be the number of binary strings of length $n$ that never contain `111`.

Classify each valid string by how it **ends** — specifically by the length of the trailing run of 1s, which can only be 0, 1, or 2 (a run of 3 is forbidden). Equivalently, build the string left to right and append one bit at a time:

- If you append a **0**, the previous prefix can be any valid string of length $n-1$.
- If you append a **1**, you must not create `111`. Split by what precedes that final 1:
  - the appended 1 forms a run of length 1 → the char before it is a 0, and everything before that (length $n-2$) is any valid string;
  - the appended 1 forms a run of length 2 → it is preceded by `01`, and everything before that (length $n-3$) is any valid string.

Collecting these disjoint cases gives the **tribonacci recurrence**:

$$a(n) = a(n-1) + a(n-2) + a(n-3)$$

with base cases (all strings up to length 2 are valid):

$$a(0)=1,\quad a(1)=2,\quad a(2)=4.$$
