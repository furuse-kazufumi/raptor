## Solution

**Setup.** Normal‑play convention: the player who takes the last stone wins, so the empty pile (n = 0) is a **loss for the player to move** — there is nothing to take. Legal moves subtract 1, 3, or 4.

**Definitions.**
- **P‑position** (Previous player wins) = a position that is **losing for the player about to move**. Every move from it leads to an N‑position.
- **N‑position** (Next player wins) = **winning for the player to move**; at least one move reaches a P‑position.

Base case: **n = 0 is a P‑position** (loser to move).

**Compute the small positions** (a position is P iff *all* of n−1, n−3, n−4 are N; it is N iff *any* of them is P):

| n | moves lead to | type |
|---|---------------|------|
| 0 | — | **P** |
| 1 | 0(P) | N |
| 2 | 1(N) only (can't remove 3 or 4) | **P** |
| 3 | 2(P) | N |
| 4 | 3(N),1(N),0(P) | N |
| 5 | 4(N),2(P) | N |
| 6 | 5(N),3(N),2(P) | N |
| 7 | 6(N),4(N),3(N) | **P** |
| 8 | 7(P) | N |
| 9 | 8(N),6(N),5(N) | **P** |
| 10 | 9(P) | N |
| 11 | 10(N),8(N),7(P) | N |
| 12 | 11(N),9(P) | N |
| 13 | 12(N),10(N),9(P) | N |
| 14 | 13(N),11(N),10(N) | **P** |

**The pattern (period 7).** The P‑positions are

$$0,\; 2,\; 7,\; 9,\; 14,\; 16,\; 21,\; 23,\ldots$$

i.e. exactly the n with

$$\boxed{n \equiv 0 \text{ or } 2 \pmod 7}.$$

**Why the period is 7 (proof of the pattern).** The move set is {1,3,4}, and the largest move is 4. Assume for one full block of 7 consecutive values (n = 7,8,…,13) the P/N types match those of n−7. Since every move (1, 3, or 4) stays within a distance ≤ 4, the type of any n depends only on the types of n−1, n−3, n−4, all lying in the previous block. Hence the types of the values 7…13 replicate 0…6, and by induction the whole sequence is periodic with period 7. The residues that come out P are 0 and 2, confirmed against the table above (0,2,7,9,14 are all P; residues 1,3,4,5,6 are all N).

**Apply to n = 40.**

$$40 = 7\times 5 + 5 \quad\Rightarrow\quad 40 \equiv 5 \pmod 7.$$

Since 5 is **not** 0 or 2 mod 7, **40 is an N‑position → the first player wins** with optimal play.

**The winning move.** The first player must move to a P‑position (residue 0 or 2 mod 7):
- 40 − 1 = 39 ≡ 4 (mod 7) → N (bad)
- **40 − 3 = 37 ≡ 2 (mod 7) → P (this is the winning move)**
- 40 − 4 = 36 ≡ 1 (mod 7) → N (bad)

So the first player **removes 3 stones**, leaving 37 (a P‑position). Thereafter, whatever the opponent removes (landing on some N‑position), the first player always restores the invariant "n ≡ 0 or 2 (mod 7)" — because from any N‑position such a move exists — driving the pile down through 37, 35 → … → 9, 7, 2, 0 and taking the last stone.

## Final answer

**The first player wins.** Position 40 satisfies 40 ≡ 5 (mod 7), which is an N‑position. The losing (P‑)positions are exactly n ≡ 0 or 2 (mod 7); the first player's winning move is to **take 3 stones**, leaving 37 ≡ 2 (mod 7), and then mirror the opponent back onto P‑positions each turn.
