**Answer: the first player WINS from 40 (it is an N-position). A winning first move is to take 3, leaving 37.**

## Reasoning via P-positions

Compute positions bottom-up (P = previous-player-wins = position is a loss for the player to move; a position is P iff **every** move from it leads to an N-position; N iff **some** move reaches a P-position). Moves: remove 1, 3, or 4.

- n=0: no moves, mover already lost → **P**
- n=1: 1→0 (P) → N
- n=2: only move is 2→1 (N) (can't take 3 or 4) → **P**
- n=3: 3→0 (P) → N
- n=4: 4→0 (P) → N
- n=5: →4(N), 2(P) → N
- n=6: →5(N), 3(N), 2(P) → N
- n=7: →6(N), 4(N), 3(N) — all N → **P**
- n=8: →7(P) → N
- n=9: →8(N), 6(N), 5(N) — all N → **P**
- n=10: →9(P) → N; n=11: →7(P) → N; n=12: →9(P)… wait, 12−3=9(P) → N; n=13: →9(P) → N
- n=14: →13(N), 11(N), 10(N) → **P**; n=16: →15(N),13(N),12(N) → **P**

The pattern is periodic with period 7:

**P-positions = { n : n ≡ 0 or 2 (mod 7) } = 0, 2, 7, 9, 14, 16, 21, 23, 28, 30, 35, 37, …**

Sanity check of periodicity: from n ≡ 0 (mod 7) the moves land on residues 6, 4, 3 (all N); from n ≡ 2 the moves land on residues 1, 6, 5 (all N; note n=2 itself has only the move to 1). From every other residue (1, 3, 4, 5, 6) some move reaches residue 0 or 2. So the classification is consistent for all n.

## Applying to 40

40 mod 7 = 5, which is not in {0, 2} → 40 is an **N-position**, so the **first player wins** with optimal play.

Winning move check:
- take 1 → 39 (39 ≡ 4 mod 7, N) — bad
- **take 3 → 37 (37 ≡ 2 mod 7, P) — winning**
- take 4 → 36 (36 ≡ 1 mod 7, N) — bad

Strategy thereafter: always move back to a pile ≡ 0 or 2 (mod 7) (37 → 35 or 30 range as opponent plays, etc.), which is always possible from any N-position; eventually the first player takes the last stone.
