## Key

Exact count = 2555757. (Satisfies a tribonacci-like recurrence a(n)=a(n-1)+a(n-2)+a(n-3).) A correct answer must give exactly this integer.

## Answer

**Answer: 2,555,757**

**Recurrence:** Let a(n) be the number of binary strings of length n with no "111" substring. Classify a valid string by its (maximal) trailing run of 1s, which must have length 0, 1, or 2:

- ends in "0": the first n−1 characters form any valid string → a(n−1)
- ends in "01": prefix of length n−2 is any valid string → a(n−2)
- ends in "011": prefix of length n−3 is any valid string → a(n−3)

These cases are disjoint and exhaustive, giving the tribonacci recurrence

  a(n) = a(n−1) + a(n−2) + a(n−3),  with a(0)=1, a(1)=2, a(2)=4.

**Computation** (verified by brute-force enumeration for n=1..15, all equal):

1, 2, 4, 7, 13, 24, 44, 81, 149, 274, 504, 927, 1705, 3136, 5768, 10609, 19513, 35890, 66012, 121415, 223317, 410744, 755476, 1389537, **2555757**

So a(24) = 1,389,537 + 755,476 + 410,744 = **2555757**.
