## Key

Exact probability = 3/5. (P(7 before 5) = P(7)/(P(7)+P(5)) = (6/36)/((6+4)/36) = 6/10 = 3/5.) A correct answer must give exactly this reduced fraction.

## Answer

**Setup.** Each roll of two fair dice has 36 equally likely outcomes.
- Ways to roll a sum of 7: (1,6),(2,5),(3,4),(4,3),(5,2),(6,1) → 6 ways, so P(7) = 6/36.
- Ways to roll a sum of 5: (1,4),(2,3),(3,2),(4,1) → 4 ways, so P(5) = 4/36.

**Reasoning.** Rolls that are neither 7 nor 5 change nothing — the process simply repeats with the same situation. So the answer is the conditional probability that, given a roll is "decisive" (either 7 or 5), it is a 7:

P(7 before 5) = P(7) / (P(7) + P(5)) = (6/36) / (6/36 + 4/36) = 6/10 = **3/5**.

**Check via infinite series.** Let p = P(win on a given roll) = 6/36, q = P(lose) = 4/36, r = P(neither) = 26/36. Then
P(7 first) = Σ_{k≥0} r^k · p = p/(1−r) = (6/36)/(10/36) = 3/5. ✓

**Check via recursion.** Let x = P(7 before 5). Conditioning on the first roll: x = 6/36 + (26/36)x ⇒ (10/36)x = 6/36 ⇒ x = 3/5. ✓

Final answer: **3/5**
