## Key

3^777 mod 1000 = 763 (last three digits '763'). A correct answer must give exactly this value with a valid method.

## Answer

Method — repeated squaring, with an order-of-3 reduction and a mod 8 / mod 125 CRT cross-check:

**Step 1: Reduce the exponent.**
- Mod 8: 3² = 9 ≡ 1, so ord₈(3) = 2.
- Mod 125: λ(125) = 100, so 3¹⁰⁰ ≡ 1 (mod 125).
- Hence ord₁₀₀₀(3) divides lcm(2, 100) = 100, so 3⁷⁷⁷ ≡ 3⁷⁷ (mod 1000).

**Step 2: Repeated squaring mod 1000.**
- 3¹ = 3
- 3² = 9
- 3⁴ = 81
- 3⁸ = 6561 ≡ 561
- 3¹⁶ = 561² = 314721 ≡ 721
- 3³² = 721² = 519841 ≡ 841
- 3⁶⁴ = 841² = 707281 ≡ 281

77 = 64 + 8 + 4 + 1, so
3⁷⁷ ≡ 281 · 561 · 81 · 3 (mod 1000):
- 281 · 561 = 157641 ≡ 641
- 641 · 81 = 51921 ≡ 921
- 921 · 3 = 2763 ≡ **763**

**Step 3: CRT cross-check.**
- Mod 8: 777 is odd, so 3⁷⁷⁷ ≡ 3 (mod 8); indeed 763 = 95·8 + 3 ✓
- Mod 125: 3⁷⁷⁷ ≡ 3⁷⁷ = 3⁷⁵ · 9 = (3⁵)¹⁵ · 9 = (−7)¹⁵ · 9 (since 3⁵ = 243 ≡ −7). 7¹⁵ ≡ 68 (mod 125), so (−7)¹⁵ ≡ −68 ≡ 57, and 57 · 9 = 513 ≡ 13 (mod 125); indeed 763 = 6·125 + 13 ✓
- The unique residue mod 1000 that is ≡ 3 (mod 8) and ≡ 13 (mod 125) is 763.

Independently verified by computation: `pow(3, 777, 1000)` = 763.

**Answer: 3⁷⁷⁷ mod 1000 = 763 (last three digits: 763)**
