**Verification of all five constraints:**
1. A before C, C before E: A=2 < C=4 < E=5. ✓
2. B immediately after A: A=2, B=3. ✓
3. D after E: E=5 < D=6. ✓
4. F before A: F=1 < A=2. ✓
5. B neither first nor last: B=3. ✓

**Proof of uniqueness:**

Step 1 — A must be in slot 2.
- From (2), B is after A. From (1), C is after A and E is after C, so E is after A. From (3), D is after E, so D is after A. Hence B, C, E, D — four distinct tasks — all occupy slots after A, so A ≤ slot 2.
- From (4), F occupies a slot before A, so A ≥ slot 2.
- Therefore A = 2, and F (the only task before A) = 1.

Step 2 — B must be in slot 3, by constraint (2) (immediately after A=2).

Step 3 — C, E, D fill slots 4, 5, 6.
- The chain C < E (constraint 1) and E < D (constraint 3) gives the strict order C < E < D, so the only assignment is C=4, E=5, D=6.

Every placement was forced with no choice points, so **F, A, B, C, E, D is the ONLY valid ordering**. (Constraint 5 is automatically satisfied — B lands in slot 3 by force — so it is redundant but consistent.)
